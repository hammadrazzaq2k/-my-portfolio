I like systems that run themselves.

A junior engineer with a builder's habits: automate it, write it down as code, and make it repeatable.

I'm Hammad Razzaq, a Junior DevOps Engineer. I grew up in Pakistan and now live in the Netherlands. What drew me to DevOps is the idea that delivering software should be boring: predictable, automated and easy to repeat.

I learn by building. I've packaged apps into Docker containers, wired up GitHub Actions pipelines that deploy on every push, and provisioned AWS servers with Terraform instead of clicking through the console.

My rule of thumb is infrastructure as code and everything automated, so systems don't wake anyone up at 3am. Right now I'm learning Kubernetes, and I'm looking for a junior role in a team that cares about good engineering.
