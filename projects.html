Portfolio CI/CD Pipeline

What I built

A pipeline that deploys this portfolio automatically. Every push to GitHub triggers a GitHub Actions workflow that builds a Docker image, pushes it to Docker Hub and updates the running container on an AWS EC2 server. No manual steps.
